# Governance

This is a public OSS project under AGPL-3.0-or-later. Contributions welcome.

## Code of Conduct

All contributors must adhere to the Contributor Covenant. See [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md).

## Decision making

- **Technical decisions** are made by the maintainers, with community input encouraged via issues and PRs.
- **Safety-critical changes** (modifications to `metal_ops.governor`, hard/escalation invariants) require maintainer review and documented rationale.
- **Licensing** decisions require unanimous maintainer agreement.

## Contribution process

1. Fork the repository.
2. Create a feature branch from `main`.
3. Make your changes (follow style conventions in existing modules).
4. Add tests for new functionality.
5. Submit a PR against `main`.
6. Ensure CI passes and obtain at least one maintainer approval.
7. Squash-merge to `main`.

## Reporting issues

Security issues: please email the maintainer privately (do not open a public issue).
Other bugs/suggestions: use GitHub issues.
